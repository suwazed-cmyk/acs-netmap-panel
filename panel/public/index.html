Cara kerjanya

ONT pelanggan→ OLT→ MikroTik lokasi⇄ VPN L2TP ⇄ VPS (GenieACS)

Tanpa VPN, GenieACS hanya bisa membaca ONT, tapi tidak bisa memberi perintah (Summon gagal), karena ONT berada di jaringan lokal yang tidak bisa dijangkau dari internet.

Dengan VPN, setiap MikroTik membuat "terowongan" ke VPS. Karena subnet ONT di semua lokasi boleh sama (misalnya semua 10.0.0.0/24), panel ini memberi setiap lokasi IP virtual yang berbeda. GenieACS melihat ONT memakai IP virtual itu, dan MikroTik menerjemahkannya kembali ke IP asli.

Langkah menambah lokasi baru

  1. Cari subnet ONT di MikroTik lokasiBuka Winbox → IP → DHCP Server → Networks. Lihat kolom Address pada jaringan yang dipakai ONT untuk TR-069, misalnya 10.0.0.0/24.
  2. Tambah lokasi di panel iniKlik ＋ Tambah Lokasi, isi nama lokasi dan subnet ONT tadi, lalu simpan.
  3. Salin script ke MikroTikKlik Salin Script, buka Winbox → New Terminal, klik kanan → Paste, lalu tekan Enter.
  4. Tunggu status hijauKembali ke panel, klik Muat ulang status. Jika tertulis Tersambung, klik Tes Koneksi untuk memastikan semua beres.
  5. Atur ONTDi ONT (atau profil TR-069 di OLT), isi URL ACS: http://192.168.42.1:7547. Setelah ONT muncul di GenieACS, coba Summon.

Remote MikroTik dari mana saja

  1. Tambah port forwardingPada kartu lokasi, klik 🌐 Remote / Port Forward → pilih Winbox → ＋ Tambah. Panel memberi alamat seperti vpn.domain.com:20001.
  2. Buka WinboxIsi Connect To dengan alamat tadi (lengkap dengan port), lalu user dan password MikroTik seperti biasa.
  3. Perangkat lain juga bisaPilih tujuan Perangkat di jaringan ONT untuk membuka web ONT atau OLT, cukup isi IP aslinya.

Port ini terbuka ke internet, jadi pastikan password MikroTik kuat. Jika di MikroTik menu IP → Services kolom Available From diisi, tambahkan 192.168.42.1.

Pertanyaan umum

Status tetap "Terputus" setelah script dipasang

Di MikroTik jalankan /interface l2tp-client print. Jika tidak ada huruf R (running): pastikan MikroTik punya internet, alamat VPS di menu Pengaturan benar, dan port UDP 1701 di VPS terbuka (ditambah UDP 500 dan 4500 jika memakai IPsec). Jika baru saja mereset password, salin ulang script terbaru.

Tes "Ping gateway ONT" gagal padahal VPN tersambung

Tes ini mencoba gateway ONT (alamat .1 di subnet ONT). Jika gateway lokasi Anda bukan .1, hasil merah ini bisa diabaikan. Jika gateway memang .1, pastikan script sudah dipasang lengkap (bagian NETMAP).

Summon di GenieACS masih gagal

Pastikan patch IP virtual GenieACS sudah dipasang dan nilai GENIEACS_CR_USE_REMOTE_ADDRESS mencakup 10.100.0.0/14 (lihat menu Pengaturan). ONT harus mengirim Inform sekali dulu setelah VPN tersambung.

Apakah aman menjalankan script MikroTik berulang kali?

Aman. Script selalu menghapus pengaturan lama bertanda "VPN ACS" dulu, lalu memasang yang baru. Pengaturan lain di MikroTik tidak disentuh.

Remote Winbox lewat VPS tidak bisa masuk

Pastikan status lokasi Tersambung dan klik Tes Koneksi. Jika baris port forward merah: salin ulang script MikroTik (aturan "remote dari VPS" harus ada), dan cek IP → Services → winbox aktif dan Available From kosong atau berisi 192.168.42.1. Pastikan juga penyedia VPS tidak memblokir port tersebut.

Apakah IP virtual boleh sama dengan ZeroTier?

Boleh, malah disarankan agar satu lokasi cukup punya satu IP virtual. Yang tidak boleh: dua lokasi memakai IP virtual yang sama, atau IP virtual sama dengan subnet lokal mana pun. Panel akan menolak otomatis.

Bagaimana menghapus VPN dari MikroTik?

Buka Script MikroTik pada lokasi tersebut, lalu salin bagian Script hapus.
