# Catatan perubahan ACS NETMAP Panel

Garis besar setiap versi. Panel menampilkan poin-poin ini di Pengaturan → Pembaruan.

## 2.22.1
- Ringkasan pembaruan add-on lebih akurat

## 2.22.0
- Alamat VPS terkunci; bisa memakai domain sendiri asalkan mengarah ke IP VPS
- Persetujuan sebelum memasang, memperbarui, atau mengganti port
- Ringkasan isi pembaruan sebelum memperbarui

## 2.21.0
- Notifikasi Telegram untuk kejadian lain (router baru, login, pembaruan, add-on)
- Pilihan logout otomatis yang lebih mudah
- Halaman pengaturan lebih ringkas

## 2.20.0
- Pemberitahuan selesai setelah add-on atau panel dipasang/diperbarui
- Tombol Install di detail add-on lebih mudah dijangkau

## 2.19.0
- Tata letak Pengaturan dua kolom
- Filter daftar router bergaya segmen
- Wizard dimulai dari nama panel

## 2.18.0
- Wizard pemasangan tanpa kode, lalu login dengan password baru
- Data panel tampil realtime tanpa penyegaran berkala
- Ikon mata di kolom password

## 2.17.0
- Buka web ONT lewat internet tanpa VPN (GenieACS → Web ONT)

## 2.16.0
- Wizard pemasangan awal
- Kelola akun GenieACS UI dari panel
